# Dataset Setup

CardioSentinel uses the MIT-BIH Arrhythmia Database provided by PhysioNet.

Dataset: https://physionet.org/content/mitdb/1.0.0/

## Setup

1. Read the dataset documentation and applicable terms.
2. Obtain the dataset from the official source.
3. Place the files in the local directory expected by the application.
4. Confirm the record files are accessible using WFDB.

The dataset itself is not included in this repository by default. Users are responsible for obtaining it according to the dataset's terms.

## Reproducibility

Record the dataset version, selected records, channel selection, preprocessing steps, and any exclusions used for each experiment.
